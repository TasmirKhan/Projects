# Tasmir Khan - Premium Developer Portfolio

Futuristic recruiter-focused portfolio built with Next.js 15, TypeScript, Tailwind CSS, and Framer Motion.

## Features
- Dark/Light mode with next-themes
- Smooth animations and glassmorphism UI
- Responsive, mobile-first layout
- SEO metadata and OpenGraph
- Reusable sections and cards
- Toast interactions and clipboard utility
- Vercel-ready deployment

## Run locally
```bash
npm install
npm run dev
```

## Production
```bash
npm run build
npm run start
```

## Deploy on Vercel
1. Push this folder to a Git repository.
2. Import project in Vercel.
3. Framework preset: **Next.js**.
4. Build command: `npm run build`.
5. Output: default Next.js.
6. Deploy.
